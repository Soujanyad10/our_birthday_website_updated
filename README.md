# 💗 Our Birthday Website

A personalised, interactive birthday surprise website created with love for someone special. This project turns a birthday greeting into a little journey filled with memories, photographs, games, music, gifts and heartfelt messages.

🎂 **A birthday celebration made personal, one memory at a time.**

## ✨ Features

- 💌 **Birthday Welcome:** A personalised birthday greeting and interactive experience.
- 📸 **Memory Gallery:** Six photographs capturing special moments and places.
- ❤️ **Our Journey:** Relationship milestones and memories presented as a timeline.
- 🎁 **Unwrap Your Happiness:** An interactive gift-unwrapping experience.
- 🎡 **Spin the Love Wheel:** Fun challenges and birthday surprises.
- 🧩 **Unscramble Our Love:** A personalised word-unscrambling game.
- 💕 **Catch My Heart:** An interactive heart-catching mini-game.
- 🐻 **Find My Heart:** A cute maze challenge.
- 🧩 **Piece My Heart Together:** A photo puzzle game.
- 🎵 **Music & Sound Effects:** Background music, game sounds and audio controls.
- 💗 **Secret Love Note:** A private romantic message hidden behind a clickable heart.
- 🎂 **Real-Life Birthday Invitation:** A personalised invitation revealing the next birthday surprise.
- 🌌 **Choose Your Birthday Universe:** Three optional, playable worlds—gaming, football and biking—with a shared romantic ending. Gamer Boy includes **Heart Invaders**, a 10-second game where pink/purple hearts add points and broken hearts deduct them.

## ⚙️ Run Locally

1. Clone or download this repository.
2. Open the `our_birthday_website` folder.
3. Keep the `assets` folder alongside the HTML files.
4. Open `happybirthdaymylove.html` in Chrome.
5. For local development, you can also use the VS Code Live Server extension.
6. Progress to the real-life invitation and select **LET'S GO!** to enter the Birthday Universe experience. Try each world; the biker game supports on-screen controls or the arrow keys and Space.

## 🖼️ Personalisation Guide

### Add Gallery Photos

Place six photographs in `assets/photos/` using these filenames:

- `01.jpg`
- `02.jpg`
- `03.jpg`
- `04.jpg`
- `05.jpg`
- `06.jpg`

### Add Gift Photos

Optional gift photographs can be added using:

- `leather-jacket.jpg`
- `bracelet.jpg`
- `photo-frame.jpg`

### Add Background Music

Place your selected MP3 at:

`assets/our-song.mp3`

The music starts when the secret envelope is opened. Browser autoplay restrictions may require user interaction.

### Personalise the Website

Open `happybirthdaymylove.html` in VS Code or another text editor.

Find the `CONFIG` section and customise:

- `milestones`: Relationship dates and descriptions.
- `photos`: Image filenames and captions.
- `letter`: Your personal birthday letter.
- `songFile`: Your selected music filename.

### Gift Buttons

The bracelet and photo-frame buttons display playful birthday confirmation messages and a two-day surprise message. These are website animations, not live courier tracking.

## 🚀 Deployment

This website is hosted using Netlify.

To publish your own copy:

1. Sign in to [Netlify](https://app.netlify.com/).
2. Connect your GitHub repository or use Netlify Drop.
3. Ensure the correct website folder and its assets are included.
4. Configure the publish directory if required.
5. Deploy your website.

For this repository, the Netlify publish directory is:

`our_birthday_website`
